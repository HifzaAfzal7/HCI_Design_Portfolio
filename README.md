## Week 1: Introduction to HCI and UX Workflow

### 1. Usability Evaluation Report 
- Evaluated the UAF Student Portal login page (mobile view).
- Found 7 usability flaws, each with a screenshot and a red box on the problem area.
- For each flaw, explained the problem and its effect on the user.
- Used Nielsen's usability heuristics to name the flaws.
- Flaws found: login form hidden beside a big photo, broken logo, label mismatch (User Name vs AGNO), red colour used for normal instructions, no hint in input boxes, no option for foreign students, unclear page title.

### 2. Improved Design Wireframe 
- Created an improved wireframe of the same login page in Figma.
- Designed two versions: Local Student and Foreign Student.
- Fixed all 7 flaws found in the evaluation.
- Made the final design in Figma Make with Phone, Tablet and Desktop views (Student, International Student, and Faculty & Staff).
- Added a short table showing each flaw and how it was improved.
